1. GitHub Repository Setup (Teamwork)
Each team must use one GitHub repository, but all members must complete their tasks individually.

Team Leader Responsibilities:

Create a new public GitHub repository for the team.

Invite all team members as collaborators.

Ensure every member has access to the repository.

Team Member Responsibilities:

Accept the GitHub repository invitation.

Create your own branch using your matric number.

Create a personal folder named MatricNumber_Name (Example: 103456_Aminul).

Inside your personal folder, create two folders: 2.1 and 2.2.

Complete both tasks in their respective folders.

Commit and push your work to your own branch.

Create a Pull Request for the team leader to review and merge into the main branch.

2. Programming Tasks
Task 2.1: Overtime Payment (Dart OOP)
Develop a Dart program to calculate an employee's total salary, including overtime payment.

Instructions:

Open VS Code and create a folder named Lab3 inside your 2.1 folder.

Create a file named myLib.dart and define an Employee class.

Create main.dart and import myLib.dart.

Create an Employee object and calculate the total payment.

Run the program using the VS Code terminal.

Last, add a screenshot of your output.
Example:

Basic Salary: RM 5,000

Overtime Hours: 7

Overtime Rate: RM 10/hour (salary ≥ RM 4,000)

Expected Output:

Total Payment = 5000 + (7 × 10) = RM 5,070

Task 2.2: Create Your First Flutter Project
Create a new Flutter project using VS Code.

Instructions:

Create a new Flutter project inside your 2.2 folder.

Open the project in VS Code.

In the AppBar, replace the default title with your name.

Run the application successfully.

Last, add a screenshot of your output.
3. Homework Submission Requirements
Every student must complete both tasks individually.

Push your work to your personal GitHub branch.

Ensure your files are available in the team repository.

The team leader should review and merge all members' work.

Every student must individually submit the GitHub repository link, even though all team members share the same repository.

Make sure your source code is accessible for evaluation.

Important:

Each student must write their own code.

Follow the required folder structure.

Complete both Task 2.1 and Task 2.2.

Submission is mandatory for every team member, not only the team leader.
